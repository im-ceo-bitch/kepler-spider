# Spyder Network — Navigation & Experience V2

Источник патча: `kepler-spider-main 5.zip` (предоставленный пользователем).

## Архитектура
- Вкладки «Кошелёк» и «Сеть» используют отдельные типизированные NavigationStack и сохраняют историю переключений.
- Wallet Control Center заменён переходом к полноценному финансовому профилю с кошельками, адресами, адресной книгой, историей, безопасностью и настройками.
- Spyder ID открывается как полноценная страница из шапки Network. Вся персонализация чата, терминала, уведомлений и сети доступна из одного места.
- Имя и аватар в заголовке беседы открывают профиль собеседника. В нём доступны реальные публичные данные, отпечаток ключа (если получен), оформление чата и блокировка.
- Убрана часть внутренних NavigationStack и лишних кнопок «Закрыть» для корректного системного возврата.
- Добавлено 10 новых неоновых цветов к двум исходным, итого 12.
- Терминал показывает короткие ответы эффектом печати без искусственного замедления длинных ответов. Переключатель «Печать» расположен в настройках терминала. Reduce Motion/Low Power учитываются.

## Сохранённые границы
- Модели кошелька, seed, E2EE-передача, APNs, Store и публичные рыночные данные не изменялись.
- Существующий серверный код не изменялся. Исправлены лишь 2 устаревших ожидания тестов APNs относительно уже существующего формата ответа.
- Не реализованы фиктивные дополнительные Spyder ID: сейчас один криптографический аккаунт на устройство. Несколько независимых профилей потребуют серверного хранилища профилей, маршрутизации и изолированных ключей.
- Неподдерживаемые публичные фото, биография, история медиа и статусы собеседника не изображаются как существующие данные.

## Контроль релиза
1. Загрузить только этот `console-update*.zip` в корень репозитория, где уже установлен код из предоставленного `kepler-spider-main 5.zip`.
2. Дождаться успешного `Console — Auto Unpack Update`. Проверить файлы `Console/WalletRootView.swift`, `Console/Features/Wallet/SpyderWalletProfilePage.swift` и `Console/Features/Chats/SpyderContactProfilePage.swift`.
3. Выполнить build-only CI на macOS через `xcodebuild`, затем TestFlight после успешной компиляции.
4. На iPhone: открыть Wallet → Кошелёк → Мои кошельки → назад; Network → Spyder ID → Цвета; Network → чат → профиль собеседника → назад; переключить вкладки без сброса; проверить терминал и уменьшение движения; удостовериться, что отправка E2EE и ключи остались прежними.

## Проверки, выполненные здесь
- unittest discover в `ci/tests` (включая новые проверки маршрутов).
- `swiftc -frontend -parse` для всех Swift исходников (это **не** Xcode typecheck).
- `swift test` для автономного `SpyderTerminalKit`.
- `npm test` для серверного JS.
- После упаковки: распаковка в чистую копию репозитория и повторная проверка содержимого ZIP и тестов.
- `WalletCore swift test` требует загрузки бинарных XCFramework из GitHub, недоступной в тестовой среде. Проверять в macOS CI.

Полноценный Xcode build отсутствует в текущем Linux-окружении. Нельзя считать TestFlight подтверждённым до зелёной macOS-сборки.
