# Spyder Terminal v6 · Light + Syntax Colors

## Совместимость и установка
Накопительный ZIP для `kepler-spider-main 3.zip`, включает все изменения v3, v4 и v5.
Загружать `console-update-spyder-terminal-v6.zip` только в корень GitHub репозитория:
внутри архива файлы уже идут путями относительно корня, без обёртки.

## Оформление
- Light: белая панель терминала, шапка, светлое поле ввода, тёмный текст.
- Dark: графитовый фон; OLED: абсолютный чёрный фон; System: фон приложения.
- Цветовой стиль как в современных IDE, но сдержанный: ключевые слова синие,
  строковые литералы зелёные, параметры фиолетовые, числа бирюзовые,
  комментарии приглушённо-серые, приглашение/префикс — Signal Red или Electric Blue.
- Подсветка отображается в скроллбеке, подсказках и прямо при вводе на iOS (нативный UITextView).
- При смене темы собственно чат и кошелёк не меняют оформление.
- Настройки RU/EN: «Светлая · белый фон» / «Light · white background».
- Команды: `сп оформление терминала светлая`; `sp terminal appearance light`;
  `сп тема терминала белая`; `sp terminal theme white`.
- Поддерживается ввод с русской клавиатуры и сохранение положения курсора.

## Ограничения
- JavaScript/SpyderScript в Developer пока **только с подсветкой**, без выполнения кода.
- Не добавлялись операции переводов, массовые сообщения или доступ к приватным ключам.
- Сервер, E2EE, блокчейн, кошелёк и GitHub Actions workflow не изменены.
- Для окончательной проверки iOS нужен `xcodebuild` на macOS (`build-only` CI).
