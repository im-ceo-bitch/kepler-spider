BLOCKS 1–3 INCLUDED:
Two tabs Wallet/Chats; terminal inside chats; real separate personas and carousel;
instant contacts by username/code/QR app link, QR photo import, connection history,
unknown-contact filter/block/hide/mute; message preview/time/unread, pin/archive/delete,
recipient delivery/read acknowledgements, recent online/typing, scoped chat persona and
next-message persona selection. Each identity pair retains separate keys and history.
No NFC, Nearby, camera scanner, HTTPS universal links or unlimited archival storage yet.
Existing retention is up to 300 encrypted messages per pair. Foreground polling is about
3 seconds in chat / 10 seconds on home. APNs is not proof of decryption or delivery.
Receipts are authenticated application acknowledgements, not signed proof against the relay.
Existing TOFU single-device E2EE trust model is unchanged; this is not a security audit.

BLOCK 4 — IMPLEMENTED IN SOURCE:
1. Spyder ID pull-down: circular avatar grows toward a nearly full-width square with 8 pt corners.
   A stronger pull (260 pt threshold) opens a fullscreen native identity viewer on release.
   Avatar tap provides an alternative. Fullscreen can close by button, downward swipe or accessibility escape.
   The drag morph is not a scaling screenshot: the native avatar canvas, size and clipping radius change.
   Fullscreen presentation uses a native cover; no cross-window matched-geometry transition is claimed.
2. Reduced Motion keeps the header avatar at its circular resting size; viewer remains accessible by tap.
3. Hero carousel: enlarged card, animated side signal sweep, actual privacy badge, active-chat count,
   native avatar/ring, chosen badge icon, quick QR/invite/style actions. Decorative glow is not presence.
4. Curated persona palette: Signal Gold, Electric Blue, Neon Violet, Emerald, Ice Cyan, Crimson Red,
   Magenta, Chrome Silver, Amber, Copper and Mono White. Five legacy colors remain decodable/supported.
   The server validates all supported raw color values; older profiles are not forcibly recolored.
5. Per-persona Style page: avatar motion, ring (thin/double/dotted/none), badge,
   glow intensity, optional independent bubble accent and existing wallpaper family.
   Avatar/main accent are shared through the existing profile protocol. Ring/glow/badge/bubble/default
   wallpaper preferences are local to this device. Contact avatars retain protocol-compatible defaults.
6. Per-persona chat defaults and per-peer overrides. Appearance save/load/reset paths, including terminal
   handlers, all carry the actual active persona. Old unscoped settings migrate ONCE to the original persona,
   never automatically to new personas, and do not overwrite an existing scoped value.
   Local reaction metadata is also scoped; invalid input cannot fall back to another persona's metadata.
7. Loading another persona no longer rewrites device-wide motion accent/avatar settings.
   Local profile metadata reloads so edits by a scoped chat store reach the home carousel on refresh.
8. Server privacy modes:
   Public: searchable username, new connections allowed subject to existing block/unknown filters.
   Private: no username search; new contacts require a capability code/QR/app link.
   Hidden: no username search; NEW INCOMING connections denied even by capability code.
           Existing contacts remain and the owner may explicitly initiate an outgoing connection.
   Public requires an actual valid username. Reserving a username alone does not publish the profile.
   Legacy privacy toggles cannot silently undo Hidden. Pending legacy invitations to Hidden are discarded.
   Hidden is not anonymity from the server; profile privacy does not erase existing contacts or conversations.
9. Profile/name/username/key-activation writes preserve the latest privacy setting transactionally.
   A delayed profile request cannot overwrite a newer Hidden selection.
10. QR on Spyder ID now uses the same validated spyder://invite?code=... payload as the invitation page,
    rather than a username payload the QR importer cannot consume. Links require installed Spyder.
11. Timelines honor view visibility, app lifecycle, Reduce Motion and low-power checks.
    Private-origin secondary personas retain their previous APNs-token restriction, even if made searchable.
