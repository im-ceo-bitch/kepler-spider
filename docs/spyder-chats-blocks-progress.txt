WHAT WAS INTEGRATED:
- Local SwiftPM product Packages/SpyderNativeCollection linked into Console and ConsoleTests.
  Its JSON vector resource is processed by SwiftPM for Bundle.module; no manual copying into main
  bundle and no remote asset loading. Existing XcodeGen workflow picks up project.yml.
- All 12 original vector artworks, 480 particle targets each, original vector renderer and six native
  backdrop implementations are preserved byte-for-byte from the attachment.
- Foreground-only SpyderSpiderLayer separated from the package's opaque two-layer wrapper.
  Live chat and preview use one app host: rear chosen wallpaper/photo; front transparent spider;
  real message bubbles stay above both. Neither background nor spider intercepts touches.
- Original two-layer SpyderChatBackground and standalone editor remain API-compatible for package
  demos. The actual app uses its existing scoped appearance store, not a new global demo store.
- Independent choices: rear wallpaper, rear accent, front spider, its 12-color palette, glow on/off,
  glow strength, visibility and size. Rear blur affects the background, keeping the spider sharp.
- Six additional gallery backgrounds: Phantom Web, Pure Void, Cyber Grid, Deep Nebula,
  Neural Circuit, Signal Waves. They work without a spider too. Existing native/animated backgrounds
  and imported photos also work under any selected spider.
- Assembly takes about 2.25 seconds using native Canvas particles. Static vector remains after it
  completes; the spider does not run a permanent TimelineView animation.
- Entry consumption belongs to the chat screen rather than a disposable background subtree.
  Incoming messages, typing, keyboard changes and rear-layer changes do not create a new entry.
  Returning from Chat/Terminal or temporary overlays does not replay an already consumed entry-only
  effect. Turning a spider on mid-conversation with entry-only mode waits for a new chat entry;
  the preview replay button remains available while animation is enabled.
- With entry-only OFF, spider/color/glow changes may replay assembly. Theme preset selection changes
  the rear/bubbles while preserving the chosen front spider and its color.
- Inactive scene, hidden chat, terminal mode, settings overlay, Reduce Motion, low power and the
  app-wide motion setting stop/prevent assembly. System controls take priority over the local toggle.
- Removed the standalone editor's duplicate theme-change/replay-token trigger; editor/store views
  have explicit main-actor isolation. Package checksum manifest regenerated for this integration.
- Existing block-4/5 JSON remains readable. No spider is forced onto old saved appearances.
  Missing new fields use safe defaults; invalid front-layer settings cannot reset an independent
  rear background. Unknown artwork/color IDs and invalid numeric ranges are normalized.
- PNG previews in the package are documentation/golden previews, NOT runtime raster spiders and
  NOT screenshots of the integrated iOS app. The original artwork NOTICE is preserved.
