# Spider Wallet — устранение P1-нарушений Design Rules

**Дата:** 10.11.2026  
**Исходники:** восстановленные Swift-файлы из повреждённого `kepler-spider-main 8.zip` (совпали побайтово с актуальной локальной копией проекта после этапов UX 1+2+3+CI Fix)  
**Статус:** исправления внесены, пройдены статические проверки, сборка Xcode не запускалась.

## Исправлено

1. **UX-01. Декоративный редактор чатов.** `SpyderChatAppearanceSettingsView` заменён на лаконичный интерфейс оформления сообщений; старый `SpyderNativeSpiderPicker` перестал выводить каталог. В новой панели нет анимированных фонов, свечения, частиц и слайдеров. При открытии панели прежние настройки приводятся к спокойному виду для соответствующей личности/чата. Существующая структура сохранённых данных и история сообщений остаются неизменными. Основной экран чатов уже использовал отдельный чистый рендерер; его не переписывали.
2. **UX-02. Подтверждения при работе с секретной фразой.** Вместо UI Switch используется однократное подтверждение (Button с квадратом/галочкой) с подписью для VoiceOver. Сохранились условия допуска к продолжению, трёхсловная проверка и запрет импорта кошелька с реальными средствами в тестовую версию.
3. **UX-03. Ложная смена темы.** Во всех трёх обработчиках legacy Terminal команда `settings.theme.set` честно сообщает, что тёмная тема пока не реализована, и не записывает ложное состояние в `UserDefaults`. Устаревшие команды декоративных тем чата также перестали сообщать об успешном применении. Обновлены RU/EN описания в каталоге команд. Функции терминала, связанные с сетью/финансами, не затронуты.
4. **UX-04. Старый селектор пауков с маленькими touch targets.** Декоративный селектор выведен из пользовательского сценария и не отображает интерактивные 40-pt элементы. Сам файл оставлен только для совместимости исходников.
5. **UX-05. iCloud Keychain / безопасность фразы.** Добавлено отдельное подтверждение перед сохранением в iCloud Keychain, пояснено отличие от обычного хранения фразы в заметках, скриншотах или облачных файлах. Внутренняя реализация `WalletICloudRecovery.saveWithConsent` не менялась.
6. **UX-06. Быстрые действия отправки.** Кнопки «Вставить», «Получатели» и «Сохранить» получили минимальную высоту 44 pt, области касания, доступные подсказки.
7. **UX-08 (дополнительно).** Во вводе фразы восстановления упрощён текст без BIP-39 в основном сценарии.

## Не затрагивалось

- Код подписания транзакций и сетевая отправка средств.
- Шифрование сообщений, хранилища секретных ключей и серверные интеграции.
- `.github/workflows` (автораспаковщик и TestFlight workflow).
- Миграция/удаление старых записей локальных настроек; формат остаётся совместимым с существующими XCTest.
