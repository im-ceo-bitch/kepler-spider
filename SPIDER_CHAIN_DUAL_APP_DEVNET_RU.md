# Spider Chain Devnet — интеграция в Root и Wallet (02.11.2026)

## Режимы
Root: создание **первичного** предложения SPD при genesis, управление процессами, отправка уже созданных тестовых монет казначейства. Новая эмиссия Mint после genesis НЕ поддерживается текущей цепью. Админский ключ и ключ транзакций различаются.
Wallet: пользовательский адрес SPD, получение/отправка тестовых токенов, сертифицированный баланс, история и подтверждения.

## Исправления безопасной интеграции
- Root: привязка снимка управления к server ID, `chain_id`, `genesis_hash` и собственному казначейству; проверка, что шлюз возвращает **тот же txid**, который был подписан. При несоответствии операция не сообщается как успешная.
- Wallet: подписанная транзакция сохраняется до HTTP POST, при пропавшем ответе можно повторить ровно тот же подписанный пакет. Старые pending-записи без пакета продолжают читаться, но не могут повторно подписываться с прежним nonce.
- Wallet: токен другой сети не наследуется автоматически; обычная сессия использует TLS, запрещает редиректы и ограничивает ответы.

## Настройка на iPhone
1. На Mac разверните службу Node и Root из этого репозитория; убедитесь, что Root status доступен по HTTPS (для локального Mac доступен localhost).
2. В Root создайте **один** Devnet genesis, выдающий первичные SPD казначейству. Запустите сеть.
3. В Root откройте «Подключение → Показать настройки доступа Devnet». В Wallet в настройках Spider Chain введите HTTPS-адрес ПУБЛИЧНОГО gateway (не адрес Root), точный `genesis_hash` и token. Не публикуйте token или seed в GitHub.
4. В Wallet откройте SPD-адрес. Переведите на него из раздела «Казначейство» Root небольшую сумму тестовых SPD.
5. Проверяйте изменение подтверждённой высоты, появление транзакции и статус финализации. HTTP 202 не означает, что перевод подтверждён.
6. При потере ответа используйте кнопку Wallet «Повторить доставку той же транзакции». Она не создаёт новой подписи.

## Важно
Это Devnet-путь, а не реальная Mainnet-эмиссия. Никаких реальных SPD или USDT эти патчи не выпускают. Переключение сети при наличии незавершённого перевода блокируется. Тесты Linux не заменяют сборку Xcode / TestFlight. Xcode CI обоих приложений обязателен до выпуска.
