# Spider Wallet — UX этап 2: структура экранов и навигация

**Дата:** 10.11.2026.  
**Основа:** пользовательский `kepler-spider-main.zip` + все изменения `console-update-ux-stage1-20261110.zip`.  
**Пакет:** `console-update-ux-stage1-2-20261110.zip` — накопительный patch ZIP (этапы 1 и 2 вместе).

## Реальные изменения в коде

### 1. Чаты — `ChatsHomeView.swift`
- В верхнем блоке только заголовок, переход в Spyder ID, кнопка создания чата, поиск, сегмент «Переписки/Контакты» и компактный фильтр.
- Архив и отображение скрытых контактов находятся в одном меню фильтров, при этом данные и прежние действия (архивировать, закрепить, скрыть, отключить уведомления, блокировать) **сохранены**.
- Убраны карусель личностей, QR, создание username и настройка Push с главного списка. Их профильные экраны сохранены; редактирование username — в Spyder ID.
- Состояния отключённой сети и ошибки сервера оставлены, чтобы не скрывать неполадки от пользователя.

### 2. «Новый чат» — `SpyderInvitePage.swift`
- Поиск по @username — первый сценарий; ниже отдельно Spyder Touch и QR с фотографии.
- Подключение по ссылке/коду, собственный QR/Share/копирование и история подключений сворачиваются; большой QR не занимает всю страницу по умолчанию.
- Deep link `spyder://invite?code=...` и найденный на фотографии код автоматически раскрывают секцию подтверждения, но не принимают приглашение без нажатия пользователя.
- Настройка разрешения неизвестным пользователям перенесена в Spyder ID.

### 3. Spyder ID — `SpyderIdentityHubView.swift`
- Переключатель «Только по приглашению» теперь в «Приватность и приглашения», с сохранением через существующий `chat.setLimitUnknownContacts`.
- Настройка видимости личностей сохранена; сетевые технические детали спрятаны в «Дополнительно».
- `chat.loadInviteSettings()` подгружает состояние при открытии профиля. Анимации и криптографические данные профиля не менялись.

### 4. Главная кошелька — `WalletHomeView.swift`
- При каждом открытии первым показывается **портфель**, а не случайно сохранённая вкладка каталога.
- «Рынок криптовалют» — отдельный очевидный переход после краткой истории; в рыночной странице есть «Вернуться в кошелёк» и объяснение, что котировки **не являются собственными активами**.
- Переключение сбрасывает позицию скролла в верхнюю часть нового раздела. Скрытый жест с левого края, конкурировавший с системным «назад», убран.
- Балансы, действия, история и рабочие методы загрузки остались прежними. Раздел тестовой сети доступен только в портфеле и остаётся свёрнутым.

### 5. Профиль кошелька и настройки — `SpyderWalletProfilePage.swift`, `WalletSettingsView.swift`
- Полный список адресов открывается по запросу и не перегружает профиль; «Получить» доступен независимо от раскрытия.
- Постоянный параметр «Скрывать суммы» перенесён в «Настройки кошелька». `@AppStorage("spyder.wallet.privacyHidden")` сохранил прежнее хранилище и поведение.
- Управление кошельками, Face ID, резервные копии, история и адресная книга не удалены.

### 6. Переписка — `ChatDetailView.swift`
- На панели сообщений теперь один главный entry point «Начать перевод». Дублирующее действие перевода убрано из меню `+`; в пустой переписке отдельный CTA остался как подсказка.
- Существующий платёжный флоу и отправка сообщений не изменены.

## Что НЕ менялось

Без изменений: backend и relay; ключи и seed-фразы; подписи; сетевые методы и авторизация; протокол сообщений; транзакции; GitHub workflow; схема проекта и Xcode настройки. Новый способ перевода денег не включён, неподдерживаемые сети не объявлены рабочими.

## Установка в GitHub

1. Удали из корня репозитория архивы `console-update*.zip`, которые ещё не были применены.
2. Загрузи **один** файл `console-update-ux-stage1-2-20261110.zip` в корень репозитория (без дополнительной вложенной папки). Отдельно первый этап устанавливать **не нужно** — он включён.
3. Сделай commit/push; существующий workflow `.github/workflows/console-auto-unpack.yml` наложит изменённые файлы.
4. Запусти iOS build/TestFlight workflow после распаковки.

Архив — **накопительный patch**, а не целый репозиторий. Его нельзя использовать вместо исходного репозитория.

## Регрессионные проверки

- `python3 ci/verify_ux_stage1.py` — 13 проверок дизайна и основных сценариев этапа 1.
- `python3 ci/verify_ux_stage2.py` — 27 проверок архитектуры экранов этапа 2.
- `swiftc -frontend -parse $(find Console Tests -name '*.swift')` — синтаксический разбор Swift.
- ZIP проверен на целостность и отсутствие абсолютных/восходящих путей, symlink и конфликтов с защищёнными workflow.

**Не проверено:** typecheck/компиляция с iOS SDK, Simulator, реальная навигация на iPhone 11 / 13 mini и контраст в Accessibility. Эти проверки обязательны перед релизом.

## Ручная приёмка после сборки

1. «Чаты» → иконка профиля → Spyder ID; возврат сохраняет список.
2. «Чаты» → новый чат → поиск @username → написать; проверь пустой поиск, загрузку и ошибку.
3. «Новый чат» → Spyder Touch / QR из фото / ввод кода; проверь ошибочный QR и deep link.
4. Spyder ID → «Приватность и приглашения» → «Только по приглашению»; проверь сохранение после перезапуска.
5. Чаты → фильтр → архив; проверь скрытые/закреплённые, свайпы, удаление с подтверждением.
6. «Кошелёк» → рынок → возврат в портфель; убедись, что портфель и рынок начинают с верхней части и не смешивают балансы с котировками.
7. Кошелёк → профиль → адреса и настройки → скрыть суммы; проверь состояние на главном экране.
8. Чат → меню `+`: перевод там не дублируется; кнопка перевода в toolbar работает по-прежнему.
