# Spyder Motion Kit — первый независимый этап анимаций

Накопительный PATCH для kepler-spider-main по состоянию на 01.11.2026.

## Что изменено

- Анимация запуска `SpyderBrandHandoff`: 1 200 частиц по альфа-маске штатного `SpyderLaunchLogo`, альтернативный `Spyder Eye` и возможность отключения.
- За основу `NativeEyeAnimationView` взят предоставленный пользователем исходный SwiftUI Canvas. Добавлено появление маленького фирменного паука в радужке при фиксации взгляда.
- `SpyderProfileAvatarView`: 12 анимационных стилей (Пульс, Орбита, Паутина, Ореол, Частицы, Радар, Волны, Узлы, Затмение, Дыхание, Искра, Минимализм).
- `SpyderMotionSettingsView`: выбор Signal Red/Electric Blue, анимации профиля, вступления, предпросмотр и настройки энергосбережения интерфейса.
- В существующие настройки добавлена кнопка «Анимации и персонализация», а превью аватара заменяет системную иконку.
- Настройки хранятся в `@AppStorage`; к фразе восстановления, приватным ключам, транзакциям, чатам и API протоколам код не обращается.

## Поведение

Системный `UILaunchScreen` остаётся статичным. Показ анимации начинается после запуска приложения; по умолчанию он выполняется только при первом открытии, а далее пропускается. При желании пользователь включает её на каждом запуске в Motion Studio. Есть кнопка «Пропустить» и автоматический fallback при Reduce Motion.

Панель «Motion Studio» доступна из существующего экрана «Профиль» -> «Внешний вид» -> «Анимации и персонализация». Живой аватар в шапке использует сохранённый выбор. Использование этого аватара в будущих карточках Spyder ID и остальных страницах — отдельный UI/UX этап.

Параметры Signal Red/Electric Blue сейчас изменяют Motion Kit и интерактивные компоненты его настроек; распространение акцентов на все страницы относится к отдельному этапу оформления страниц.

## Как установить

Положить `console-update-motion-kit-20261101.zip` в корень GitHub репозитория. Существующий `.github/workflows/console-auto-unpack.yml` распакует только перечисленные файлы и удалит ZIP после фиксации результата. ZIP не содержит wrapper-директории и не меняет workflow.

## Проверки перед выдачей

В окружении Linux доступен `swiftc -frontend -parse` для проверки синтаксиса, Python unit checks и проверка наложения ZIP. **Полноценный `xcodebuild`/SwiftUI typecheck на Linux недоступен**, поэтому это **не подтверждённая Xcode сборка**. Запустить build-only Gate на macOS перед TestFlight, затем проверить на iPhone 11/13 mini, включение Reduce Motion, светлую/тёмную тему и закрытие сцены во время проигрывания.
