# Spider Wallet — CI-исправление после UX Stage 1+2+3

## Почему остановился TestFlight

Лог GitHub Actions `logs_116061509308.zip` показал остановку в шаге **Verify source and run unit tests**, до Xcode archive / App Store Connect upload. Из 145 Python-тестов: 8 FAIL и 1 ERROR. Причина: старые проверки исходников искали интерфейсные детали, удалённые или перенесённые в UX-этапах 2–3.

Обновлены 8 модулей проверок в `ci/tests/` (сохранили проверки безопасности):

- `test_wallet_catalog_block56.py` — вместо удалённого переключателя ожидает явную навигацию «Кошелёк → Рынок → Назад».
- `test_spyder_control_center.py` — вместо скрытого edge-swipe проверяет доступную 44 pt кнопку профиля.
- `test_spyder_live_release.py` — подтверждает, что Spider Devnet скрыт без конфигурации и по умолчанию свёрнут, а отправка разрешена только при подтверждённых реквизитах USDT из чата.
- `test_spyder_terminal_integration.py` — проверяет отдельную кнопку перевода в toolbar чата.
- `test_wallet_address_book_next.py`, `test_wallet_evm_stage1.py`, `test_wallet_evm_stage2.py` — проверяют, что отправка на произвольный адрес невозможна, без удаления защиты.
- `test_wallet_portfolio_ui.py` — проверяет, что Spider Devnet виден только при выборе портфеля, наличии конфигурации и раскрытии.

### Проверки в текущем окружении

- Полный набор: **145 Python-тестов**, **0 FAIL**, **0 ERROR**, **21 skipped**. Swift-бинарные проверки пропущены, так как здесь нет Xcode/macOS и полноценная проверка Swift-компиляции локально не выполнялась.
- Ранее выполненные UX-скрипты этапов 1, 2 и 3 проверяются отдельно.
- Это не подтверждение успешного TestFlight: после загрузки архива повторно запустите исходный workflow.

### Состав обновления

Архив накопительный: UX Stage 1+2+3, этот CI-hotfix и исходные инструкции UX-этапов. Папку `.github/workflows` не изменяет. SwiftUI, код транзакций, ключи, криптографию и API исправление не меняет.

Загружайте архив в **корень репозитория** через ваш обычный GitHub-распаковщик. Если в исходниках после Stage 3 были ручные изменения, сначала сравните одноимённые файлы.
