# Spyder Wallet — каталог Топ-250 (обновление к Block 5–6)

## Установка

Загрузить **один** `console-update-spyder-wallet-top250-20261101.zip` в корень репозитория и дождаться успешной распаковки. Он **включает полностью предыдущий Block 5–6**, потому устанавливается как на Chat Unified + LIVE Dual Theme, так и поверх уже установленного Block 5–6. Папка `.github/workflows` и файлы чата/ключей не изменены.

## Поведение

- В «Кошелёк» → «Криптовалюты» сначала отображаются **50** монет из списка **Топ-250 CoinGecko по рыночной капитализации**.
- Кнопка **«Открыть ещё»** раскрывает следующие **50**: 50 → 100 → 150 → 200 → 250; после последней порции кнопка скрывается.
- Весь список до 250 загружается одним запросом `/coins/markets?vs_currency=usd&order=market_cap_desc&per_page=250&page=1&sparkline=true&price_change_percentage=24h`. Поэтому **поиск** по имени или тикеру охватывает все загруженные Топ-250, включая пока скрытые строки.
- Доступны сортировка, избранное, логотипы, текущие USD-цены, изменение за 24 часа, мини-графики за неделю и индивидуальные исторические графики.
- **BTC / ETH / SOL**: при активном Coinbase WebSocket отображается свежая цена с маркировкой **LIVE · Coinbase**. Изменение за 24 часа приходит из CoinGecko. У других монет цена из CoinGecko — это **НЕ потоковые live-ticks**: запрос повторяется примерно раз в 120 секунд при активном экране, а источник кэширует котировки примерно 1–5 минут. В интерфейсе показан источник и время получения.
- Если API возвращает менее 250 валидных монет либо недоступен, интерфейс не создаёт фиктивные позиции и суммы. При ошибках сохраняется последний успешно полученный кэш; устаревшие цены маркируются.
- Только просмотр рыночного каталога: появление монеты в этом списке НЕ подтверждает поддержку её сети в кошельке или возможность переводов.

## Область патча

Изменения только в каталоге Wallet, строках RU/EN, тестах и обработке pull-to-refresh Wallet. Важные файлы Chat Unified (`ConsoleApp.swift`, `WalletRootView.swift`, сервер, APNs, ключи) **не перезаписываются**.

## Контроль качества

В локальной Linux-среде проведены Swift syntax parse всех исходников, запуск реального Swift-драйвера моделей и пагинации/поиска, 46 Python CI-тестов, проверка каталога `.strings`, `ci/verify_repo.py`, проверка ZIP и пробное наложение на базу с Chat Unified. Настоящий `xcodebuild` на macOS, визуальные UI-тесты на iPhone и сетевые запросы в реальном приложении здесь недоступны — **успешный TestFlight не гарантируется**. После распаковки выполнить сначала build-only CI, затем TestFlight.
