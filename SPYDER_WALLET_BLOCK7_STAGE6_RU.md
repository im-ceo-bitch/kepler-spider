# Spyder Wallet — Block 7 Stage 6: предрелизные предохранители EVM

## Готовность

**NO-GO для реальных USDT/ETH и для запуска реальной отправки.** Stage 6 реализует проверку структуры подписанных EIP-1559-байтов, устойчивую запись попытки по nonce и проверку двух независимых RPC на Sepolia. Он не выполняет реальную транзакцию, не обеспечивает криптографическую проверку secp256k1/Keccak и не подтверждает восстановление на другом устройстве.

## Новое

1. `WalletEVMSignedEnvelopeGuard.swift`: строгий декодер EIP-1559 `0x02 + RLP` без пользовательских библиотек; проверка полей `chainId=1`, nonce, maxPriorityFee, maxFee, gas, контракта/получателя, ETH value, ERC-20 data, пустого accessList, parity, положительных r/s и low-s. Неканоническое RLP отвергается. Проверка вызывается после `AnySigner.sign` в `WalletEVMOfflineSigner.swift`. Это **структурная** проверка; подпись и адрес отправителя по r/s криптографически пока не восстанавливаются.
2. `WalletEVMNonceJournal.swift`: **только под тестовым флагом** `SPYDER_EVM_RELAY_TESTS`. Атомарная запись резервирования nonce до попытки отправки, запрет повторного nonce/txHash, сохранение неопределённого результата и fail-closed при повреждённом файле. В журнале нет мнемоник, приватных ключей или raw-транзакций. Отсутствует координация между несколькими процессами и жёсткий fsync; поэтому не считать его production-авторитетом.
3. `WalletEVMSepoliaProbe.swift`: read-only проверка chain ID `11155111` и высоты блоков у двух разных HTTPS-хостов; не содержит подписи, публикации или ключей.
4. `WalletRecoveryParityTests.swift`: Xcode-тест публичной детерминированной seed-фразы Wallet Core (ETH/BTC/SOL), не извлекает личные секреты и **не** заменяет реальную проверку восстановления на другом iPhone.
5. Компилируемые Swift-тесты положительных и отрицательных сценариев и Python CI-регрессии. Swift 5 и Swift 6 проверяются независимо.

## До допуска к тестовым реальным активам

- Успешный `xcodegen generate`, `xcodebuild build` и `xcodebuild test` на macOS с iOS Wallet Core (включая Signing/Recovery XCTest).
- Независимое вычисление Keccak-256 `rawTxHash` и криптографическое восстановление отправителя из подписанного EIP-1559 (secp256k1), сверка с фактическим адресом владельца.
- Безопасный механизм отправки через Sepolia с надёжной авторизацией, журналом nonce и защитой от двойной отправки после crash/restart; подтвердить tx explorer/receipt и восстановление после timeout.
- Проверить смену устройства, ручной импорт BIP-39 и повторное получение ETH/BTC/SOL адресов. Проверить фактическое поступление/вывод в тестовой сети.
- Выполнить независимый аудит транзакционного движка, корректности ключей, комиссий и подписей.
- Только затем рассмотреть отдельный релизный gate и ограниченный микротест 1–2 USDT ERC-20 с достаточным ETH на комиссию.

Этот ZIP не меняет Chat, Terminal, server, WalletVault, настройки GitHub Workflows и не включает Mainnet-отправку.
