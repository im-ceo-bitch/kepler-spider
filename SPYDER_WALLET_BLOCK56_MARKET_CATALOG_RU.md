# Spyder Wallet — Block 5 / Block 6: Market Catalog, Wallet navigation

Основа: `kepler-spider-main 3.zip` + `console-update-chat-unified-20261101.zip` + `console-update-spyder-wallet-live-dual-theme-chat-compatible-20261101.zip`.
Этот PATCH предназначен для установки **после последнего совместимого Wallet обновления**, только в корень репозитория с существующим распаковщиком.

## Block 5 — публичный каталог криптовалют

- **50** криптовалют сразу при открытии каталога (`/coins/markets` получает один срез топ-250).
- По нажатию «Открыть ещё» последовательно показываются **ещё 50**: 50, 100, 150, 200, 250. Поиск охватывает **все топ-250**, включая пока скрытые строки.
- Реальные цены USD, изменения за 24 часа, ранги по капитализации, логотипы с доверенных CoinGecko CDN, 7-дневные мини-графики из ответа API.
- Переход на страницу любой загруженной монеты: интерактивный исторический график по реальным данным CoinGecko (1Д/7Д/1М/3М), капитализация, 24-часовой оборот и избранное.
- BTC, ETH и SOL: кнопка перехода в уже установленный Coinbase LIVE-график. Другие монеты **не выдают** исторический CoinGecko-график за биржевой WebSocket.

## Block 6 — UX и безопасные границы

- Под основным портфелем и действиями кошелька: нативный переключатель **Активы / Криптовалюты**.
- «Активы» — только фактически поддерживаемые адреса/токены и полученные по RPC балансы; «Криптовалюты» — просмотр рынков, не функциональность переводов.
- Сохранение выбора вкладки, локальное избранное, поиск, сортировка, адаптивный светлый и тёмный интерфейс, системный Reduce Motion.
- Кэш публичных рыночных данных; обработка HTTP 429, отмен запросов, ограничение размера ответа и числа графических точек; отображение устаревших данных с их временем.
- Никаких новых блокчейн-сетей для реального хранения или отправки в этом PATCH **нет**. Mainnet Send не меняется.

## Проверка

Проведены: Swift `-frontend -parse`, реальный `swiftc -typecheck` для Foundation-моделей, запуск Swift runtime тестов декодера, Python CI и серверные тесты регрессии; проверена побайтовая сохранность файлов Chat Unified при наложении архива.

**Не выполнены:** полноценная сборка Xcode, UI-тесты iPhone/iPad, live-испытание публичного CoinGecko API на целевом устройстве, аудит безопасности. Успешность TestFlight не гарантируется до фактической сборки.

## Важно для production

- CoinGecko Public API имеет переменные лимиты и может возвращать 429; для коммерческой нагрузки рекомендован собственный прокси с кэшем и соответствующим API тарифом. Не помещайте секретный платный API-ключ в iOS-приложение.
- Из-за суточных ограничений CoinGecko все рыночные цены периодические; Coinbase WebSocket остаётся отдельным live-источником только для BTC/ETH/SOL.
- Рыночный каталог содержит публичные рыночные инструменты, **не активирует поддержку их смарт-контрактов, сетей, подписей и отправок**.
