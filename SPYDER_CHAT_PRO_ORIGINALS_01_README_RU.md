# Spyder Wallet — Pro Chat + Originals 01

**Основа:** пользовательский `kepler-spider-main 6.zip` (02.11.2026), патч не накопительный.

## UI

- Широкая верхняя полоса «Чат / Терминал» удалена только из **переписки**. Терминал
  остался в navigation bar (иконка `terminal`), а возврат в чат — иконка `bubble.left`.
  Старый терминал также доступен через меню `+` для совместимости.
- Заголовок контакта / системный Back сохраняются. Системные safe area не отключаются:
  градиенты и фон рисуются **под** ними, а интерактивные элементы остаются в пределах
  safe area, в том числе при открытой клавиатуре. Это нужно для жестов и Dynamic Island.
- Нативный SpyderLayeredChatBackdrop (с коллекцией пауков) сохранён: ничего не заменено
  на старый Canvas-only фон. Градиент под прозрачной панелью навигации.
- Выбор личности через `+`, с индикацией только при переопределении личности на следующее
  сообщение. Пустая строка «Пишешь как» больше не занимает место у каждого пользователя.
- Мягкий градиентный composer, компактные текстовые пузыри с локальным временем и
  read/delivered внутри пузыря. Размер шрифта 16 pt; стили пузырей и цвет из сохранённых
  per-contact настроек, без сброса на дефолты.

## Originals 01

- Восемь вариантов движения одного процедурно построенного 3D-паука SceneKit.
- Вход/отправка в панели рядом с вводом либо через `+`.
- Текстовый идентификатор `spyder:originals:v1:<action>` передаётся только через
  **существующее** E2EE-сообщение. Никаких новых серверных API / медиа-загрузок.
- При отправке стикера незавершённый текстовый черновик не сбрасывается.
- В превью списка чатов выводится человекочитаемая подпись вместо технического кода.
- Клиент более старой версии без функции Originals увидит исходный текстовый код.

## Проверки и ограничения

- Проверка Swift-синтаксиса (`swiftc -frontend -parse`) — не эквивалент Xcode build.
- Python CI-тесты специфичные чату, терминалу, Originals; Node-протоколы/relay.
- ZIP после упаковки повторно накладывается на оригинал в чистом каталоге, сверяются SHA256.
- **Требуется Xcode на macOS**: `xcodegen generate`, затем `xcodebuild build` для схемы
  `Console` (iOS simulator), затем устройство iPhone 11 и iPhone 13 mini.
- Визуально проверить реальный SceneKit-паук, изменения высоты при клавиатуре,
  тему `Phantom Web`, Light/Dark, работу VoiceOver и iOS 27.
- На этой стадии геометрия 3D procedural, а не финальная фотореалистичная 3D-модель.
- Существующие чаты, сервер, wallet, криптоядро, workflows не изменяются, кроме
  локального формата превью и точечных SwiftUI UI-файлов.
