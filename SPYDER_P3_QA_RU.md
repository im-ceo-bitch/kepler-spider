# Spider Wallet — P3: transaction UX / recovery (11 ноября 2026)

Применена основа из загруженного `kepler-spider-main 9.zip`. Данный ZIP — **не полный репозиторий**: он накладывает изменения на ту же ветку, где уже стоят UX 1+2+3, P1 и P2.

## Изменения в приложении

1. **USDT в чате.** После подтверждения отправки возникает уникальная для открытого экрана попытка. Повторная отправка через этот экран не предлагается даже при неопределённом ответе RPC. Пока запрос идёт, виден процесс и отключены действия закрытия. Если в журнале есть запись, открывается карточка с хешем; если достоверного результата нет — понятное предупреждение и выход к истории.
2. **Карточка USDT после операции** теперь не блокируется `disabled` на всём контейнере: можно раскрыть детали, скопировать хеш и повторно проверить сеть. Обновление статуса не отправляет деньги заново.
3. **SPD Devnet.** Защита от повторной попытки после сетевого сбоя, состояния «отправляем» и «результат неизвестен» разделены. Ошибка доступна в раскрываемых подробностях, вместо прерывающего alert. Во время отправки нельзя случайно закрыть форму.
4. **Получение.** При изменении проверенного публичного адреса повторно требуется подтверждение сети. Метка «адрес скопирован» сбрасывается при уходе приложения в фон.
5. **Accessibility.** Статус операций озвучивается как изменяющийся; кнопка ручной проверки сети показывает ожидание и не запускает параллельные проверки.

## Приёмка на iPhone 11 и iPhone 13 mini (после TestFlight)

- [ ] Кошелёк → Отправить: произвольные адреса/ETH/USDC действительно остаются только предпросмотром.
- [ ] Чат → USDT: подтверждённые реквизиты; на экране проверки есть адрес, сумма, ETH-комиссия; закрытие/повторные касания не запускают дубли.
- [ ] После отправки: карточка статуса кликабельна, хеш доступен, «Обновить статус» проверяет RPC без повторной транзакции.
- [ ] При ошибке RPC/потере интернета: предупреждение без ложного успеха; экран не предлагает немедленно отправить снова.
- [ ] SPD Devnet: кнопка во время отправки отключена, после сбоя статус/ошибка видны; повторная отправка без проверки невозможна.
- [ ] Получение BTC/ETH/SOL/USDT: при смене сети или кошелька прежний QR скрывается до повторного подтверждения.
- [ ] Переключить приложение в фон после копирования: метка «скопировано» сбрасывается.
- [ ] Проверить Dynamic Type (крупный и максимальный), VoiceOver и Reduce Motion.
- [ ] Проверить Face ID, отказ в авторизации, таймаут RPC, слабую сеть и возврат из фонового режима.

## Ограничения

Эта поставка закрывает **кодовые исправления транзакционных сценариев P3**, но не является завершённой приёмкой всего P3. Для оценки визуальной геометрии, жестов и итогового TestFlight нужны результаты Xcode и тестирование на устройстве. Не запускать реальные денежные операции ради проверки без отдельного безопасного тестового плана.
