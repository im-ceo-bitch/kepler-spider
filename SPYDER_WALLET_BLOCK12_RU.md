## Реализовано в этом обновлении

- Новый UX первого запуска: создание 12 слов, скрытие и показ, проверка трёх слов, локальное сохранение с Face ID/кодом устройства.
- Явное копирование фразы в **локальный буфер обмена на 45 секунд** с предупреждением. Буфер обмена не считается надёжным способом резервного копирования.
- Импорт 12/24 BIP-39 английских слов через SecureField + отдельное действие «Вставить из буфера обмена».
- По **отдельному согласию** — сохранение в синхронизируемый Apple iCloud Keychain и восстановление с тем же Apple Account. Синхронизация требует включённого iCloud Keychain. Это не гарантия наличия копии и не замена офлайн-записи.
- Сохранён предыдущий Keychain-аккаунт `bip39-english-mnemonic`, чтобы не требовать повторного импорта существующего кошелька.
- Несколько отдельных seed-кошельков: добавление/импорт, список, переключение, переименование и изоляция адресов/кэша/балансов.
- Страницы BTC/ETH/SOL с балансом, адресом, переходом в block explorer, действиями Send/Receive.
- Экран проверки неподписанного Mainnet-перевода: актив, адрес, сумма, предупреждение, что сетевая комиссия и подпись ещё не готовы.
- Переключатель RU/EN в профиле; базовый пакет строк для новых экранов. Некоторые существующие старые экраны (например, экспериментальные чаты/Devnet) всё ещё имеют исходные непереведённые строки.
- Apple SF Symbols, `.symbolEffect` при проверке/успехе, системные haptics и Reduce Motion где поддерживается.
- Privacy Mode — скрытие портфеля и сумм в списке активов.
- Отмена устаревших результатов загрузки при переключении активного кошелька.

## НЕ готово к production

- **Отправка BTC, ETH, SOL и ERC-20 в Mainnet выключена**, включая WalletCore signing и RPC broadcasting. Проверка формата адреса на экране — НЕ криптографическая проверка checksum и НЕ подтверждение доставки.
- Для реальной отправки требуются chain-specific signer, комиссия, UTXO/nonce, nonce-locking, transaction simulation, мониторинг pending/confirmed, безопасное повторное выполнение, работа с RPC-провайдерами и интеграционные тесты.
- Нет Mainnet-истории внутри приложения, token explorer, swap и полного account discovery.
- У iCloud Keychain backup в текущем интерфейсе **один слот для одной фразы**. Если у пользователя несколько кошельков, необходимо сохранить резервные фразы каждого независимо. Попытка записать другую фразу поверх текущей копии блокируется.
- BIP-39 passphrase (дополнительное слово/25-е слово) не поддерживается; соответствующие кошельки сюда импортировать нельзя.
- Нет независимого security-аудита. Нельзя вводить в эту тестовую версию seed от кошелька с реальными активами.

## Требуемые проверки на macOS/Xcode

1. `xcodegen generate` (или штатный GitHub TestFlight workflow, если он создаёт проект автоматически).
2. `xcodebuild -project Console.xcodeproj -scheme Console -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build`.
3. Проверить создание -> запись -> проверка -> открытие; импорт с правильной/неправильной контрольной суммой; Face ID/код устройства; уход приложения в background.
4. Проверить второй кошелёк, адреса в каждой сети, переключение кэша, удаление/reinstall только на тестовом устройстве; восстановление из iCloud отдельно от локального Keychain.
5. Проверить приложение на iPhone 11/13 mini, затем iPad: клавиатура, safe areas, переходы, тёмная тема, Dynamic Type и VoiceOver.
6. Не тестировать отправку реальных средств: функциональность отключена до последующего подписания и проверок.
