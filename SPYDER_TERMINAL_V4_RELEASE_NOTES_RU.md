# Spyder Terminal v4 — этапы 1/2 (инкрементальное обновление)

**Основа:** `kepler-spider-main 3.zip` **с применённым v3 или без него**. Архив накопительный: содержит необходимые файлы v3 + v4.

## Что изменено

- В основном `WalletRootView` появился третий раздел **Терминал**, доступный вне переписок.
- Глобальный терминал повторно использует `SpyderChatTerminalSwitchView` и единый движок команд.
- Команды в глобальном терминале работают только через существующие подтверждённые сервисы: статус сети, собственный профиль, контакты, загруженные балансы, получение средств, история, тема и язык приложения.
- Внутри чата остался существующий переключатель **Чат | Терминал**, привязанный к верифицированному `peerID`.
- Каталоги RU/EN расширены: **30 Action ID**, больше алиасов для Standard, `сп`/`sp`, добавлены `clear` и `capabilities`.
- Автодополнение в используемом SwiftUI-компоненте больше не предлагает команды, для которых у текущего терминала нет обработчика. Ручной ввод недоступной команды отклоняется защищённым Host.
- Команда `сп доступные команды` / `sp capabilities` показывает лишь команды, реально доступные в текущем терминале.
- Часть системных ответов локализована для RU/EN; для полной локализации сообщений существующих обработчиков нужны дальнейшие работы.
- Код кошелька (ключи, подписи, E2EE, переводы), API сервера и `.github/workflows` НЕ изменялись.

## Обязательная проверка перед TestFlight

1. Загрузите только `console-update-spyder-terminal-v4.zip` в **корень репозитория**. Отдельная установка v3 не требуется. Если v3 уже установлен, повторная установка поверх него тоже поддерживается.
2. Дождитесь успешной распаковки; файлы внутри архива имеют пути относительно корня репозитория.
3. Добавьте **отдельно** `spyder-terminal-build-only.yml` в `.github/workflows/` через интерфейс GitHub.
4. Actions → **Spyder Wallet — Build Only (No TestFlight)** → Run workflow.
5. При красном build **не запускать TestFlight**. Приложите лог — исправим фактическую ошибку компилятора.

**Проверено локально:** Swift Package — 28 тестов, 0 ошибок; Python CI — 89/92 (три старые проверки Sonic Push и аватара падают и на исходной базе). Проверен Swift-синтаксис.

**НЕ проверено:** полноценный xcodebuild на macOS и сборка TestFlight. Без реального Xcode невозможно обещать отсутствие падения сборки.
