# Spyder Wallet — объединённое обновление Portfolio + Market Data Engine

Основа: `kepler-spider-main 3.zip`. Один ZIP включает оба обновления:

1. `console-update-spyder-wallet-portfolio-20261101.zip` — новый UI портфеля, страницы активов и исправление Safe Area.
2. `console-update-spyder-wallet-market-engine-20261101.zip` — CoinGecko-котировки, 24-часовая динамика, логотипы, нативные графики Swift Charts, кэш и тесты.

**Правило объединения:** общие файлы взяты из более свежего Market Data Engine; все файлы Portfolio Upgrade сохранены. Ни один из двух предыдущих ZIP отдельно загружать не требуется.

**Установка:** загрузить этот ZIP в корень GitHub-репозитория, дождаться успешной распаковки и проверить изменения в `main`, затем запустить build-only workflow перед TestFlight. Пути внутри архива относительные к корню репозитория, без внешней папки.

**Проверки на исходном архиве с наложением обновлений:** 29/29 Python unittest, 7/7 Node MessageChain; синтаксический разбор всех Swift-файлов; `plutil -lint` для RU/EN Localizable.strings. Эти проверки не равнозначны полноценной Xcode-сборке на macOS. Сборка TestFlight и работа сетевых запросов на реальном устройстве не подтверждены.

**Границы:** отправка реальных BTC/ETH/SOL по-прежнему не готова и остаётся заблокированной. API CoinGecko обновляется периодически, а не в потоковом режиме. Чат и система ключей в обновлении не меняются.
