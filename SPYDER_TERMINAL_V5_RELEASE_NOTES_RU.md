# Spyder Terminal v5 · 2026-11-01

## Назначение
Накопительное обновление для `kepler-spider-main 3.zip`.
Совместимо с исходной версией репозитория и с репозиторием, где уже установлен v3/v4.
Файлы расположены относительно корня репозитория. Вложенной папки-обёртки нет.
Существующие `.github/workflows/`, server E2EE и криптографию не изменяет.

## Изменения
- Каталог Standard вырос с 30 до 35 Action ID: новые команды языка, акцента,
  оформления, автодополнения и размера шрифта терминала — на русском `сп` и English `sp`.
- Добавлен `TerminalPreferenceCommands.swift`: проверка допустимых аргументов
  и изменение локальных настроек терминала без доступа к кошельку и ключам.
- Автодополнение предлагает значения параметров для тем Chrome/Cyberpunk/Thunder,
  оформления терминала, языка и прочих фиксированных параметров.
- Подсказки по-прежнему фильтруются по списку реально подключённых действий.
- Профиль: `сп измени имя на ...` / `sp change name to ...` использует уже существующий
  `SpyderChatStore.updateDisplayName(...)` с серверным сохранением.
- Push: `сп включи уведомления` / `sp enable notifications`, а также выключение —
  через существующие `enablePush()` / `disablePush()` в чат- и глобальном терминале.
  В ответе отделена локальная настройка от возможной незавершённой APNs-регистрации.
- Ответы чат-терминала для подключённых операций расширены до RU/EN.
- Developer без runtime не запускает скрипты, но позволяет вернуть Standard командой.
- Исправлено устаревшее описание недоступных действий, мешавшее старому CI-тесту.

## Проверки
- Linux Swift Package (`swift test`): **35 тестов пройдено**.
- Python CI (`pytest -q ci/tests`): **96 пройдено / 3 провалено**.
- Три прежних сбоя: тесты `Sonic Push` (2) и `SpyderProfileAvatarView` (1).
- Swift-файлы обновления проверены парсером (`swiftc -frontend -parse`).
- Наложение обновления проверено на исходный ZIP и после v4; итоговое содержимое совпадает.
- `xcodebuild` / iOS компиляция не выполнялась: macOS/Xcode недоступны в текущей среде.

## Границы безопасности
- `wallet.send`, `chat.broadcast`, `profile.bio.set`, `chat.pin`, `chat.mute`,
  `chat.unmute`, `network.view` не получают ложных обработчиков.
- Фактическое состояние APNs может требовать завершения регистрации / отмены на сервере.
- Подсказки никогда не выполняют команды самостоятельно.
- Сборка через `build-only` GitHub Actions остаётся обязательным шлюзом до TestFlight.

## Установка
1. Загрузить `console-update-spyder-terminal-v5.zip` в **корень** GitHub-репозитория.
2. Дождаться завершения имеющегося распаковщика.
3. Запустить build-only workflow для iOS; при ошибках приложить лог сборки.
4. Не запускать TestFlight, пока `xcodebuild` не завершился успешно.
