# Console → Spyder Wallet: что сохраняем и что меняем

**ОСТАЁТСЯ**
- Bundle ID `com.console.beta`
- Project / XcodeGen target / Scheme `Console`
- GitHub Actions для подписанной загрузки в TestFlight и имена Apple Secrets
- Существующая карточка приложения в App Store Connect (если она принадлежит тому же Bundle ID)

**МЕНЯЕТСЯ**
- Имя на устройстве: `Spyder Wallet`
- Весь старый SwiftUI интерфейс Console, модели, его исходный messaging, клиентский Cloudflare API и логика входа удалены из iOS-исходников
- Два раздела Wallet / Chats, собственные флоу и адаптивная чёрно-белая тема
- Иконка паука

**ЕЩЁ НЕ СДЕЛАНО**
- Настоящий криптокошелёк, транзакции, серверный чат, pairing, реальные QR, локальный Keychain и резервное восстановление
- Проверка Xcode build на macOS, загрузка сборки и Apple Review

**Как установить из чистого репозитория**: заменить файлы репозитория этим ZIP с сохранением `.git` и GitHub Secrets, создать коммит и запустить `.github/workflows/testflight-ios.yml`.

**Как применить через старый ZIP-бот**: загрузить `console-update-spyder-wallet-v1.zip` в корень старого GitHub-репозитория. Он удалит старые клиентские файлы через `.console-delete` и установит новый UI. Этот быстрый путь сохраняет прежний Cloudflare backend и старый workflow только как временную совместимость: без их ручной замены полного очищения не будет.

**Требования Apple**: app с реальными криптокошельками должен распространяться от аккаунта разработчика-организации. Резкая смена назначения приложения требует новой проверки, обновления описания, скриншотов, Privacy Policy и сведений о сборе данных. Нельзя обещать «мгновенный» публичный релиз.
