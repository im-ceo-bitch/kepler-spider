# Spyder Sonic + Identity + Chat Experience, совместимо с Top-250

Этот ZIP — **единственное** обновление для установки поверх уже распакованного
`console-update-spyder-wallet-top250-20261101.zip` и предыдущих Motion Kit/Network UI/Chat Unified.
Не загружайте отдельно предыдущие Sonic+Identity и Stage 3 ZIP: их изменения объединены здесь.

## Что входит
- Stage 1/2: Sonic (3 CAF), регистрация и диагностика push, Cloudflare API настроек
  уведомлений, единый Spyder ID, редактирование публичного имени.
- Stage 3: новые пузыри сообщений, 5 процедурных фонов, локальные реакции,
  анимации, персонализация каждого чата.
- Восстановленный анимированный аватар WalletHome на базе актуального Top-250.
- Исправление существовавшего в Top-250 CI-теста: typecheck только реально
  существующего WalletCatalogModels.swift (нет WalletMarketModels.swift).
- Новый интеграционный регрессионный тест двух этапов и Top-250.

## Не изменяем
- Действующие модели, Store и UI Top-250, кроме одной кнопки аватара в шапке WalletHome.
- `.github/workflows/*`, `project.yml`, ключи, seed, криптографический E2EE-формат,
  `server/wrangler.jsonc`, структуру Durable Objects.
- `ci/tests/test_spyder_live_release.py` из вашего текущего main: более новый тест сохраняется.

## Границы функциональности
- Emoji-реакции пока **локальные** и не синхронизируются.
- Push и пользовательский CAF заработают после успешного деплоя новой серверной части
  и TestFlight-сборки с корректным APNs; реальные APNs-уведомления не проверены.
- Защищённость чатов не прошла независимый криптографический аудит.

## Установка
1. Дождитесь завершения текущих GitHub workflows и убедитесь, что корень репозитория
   свободен от других `console-update*.zip`.
2. Загрузите этот ZIP в корень, дождитесь зелёного Console — Auto Unpack Update.
3. Проверяйте Cloudflare deploy, при ошибке НЕ повторяйте вслепую: пришлите лог.
4. Запустите build-only CI, затем TestFlight.
5. Проверьте профиль из кошелька и чатов, фон переписки, звук, сетевую доставку,
   пуши на втором iPhone и Top-250.

## Проверки перед выдачей
- Синтаксический parse Swift на Linux, Node tests и Python CI (не iOS typecheck).
- Проверка архива, имитация распаковки и сравнение ключевых Top250-файлов.
- `xcodebuild` и физические iPhone не доступны в среде подготовки.
