# Spyder Wallet — Immersive Live Market (светлая / тёмная тема)

## Основа и установка

Исходный ZIP: `kepler-spider-main 3.zip`. Патч накопительный: включает предыдущие Portfolio Upgrade, Market Engine и Coinbase Live Market. Если предыдущие патчи установлены, повторно их загружать не нужно. Загружать в корень репозитория как `console-update*.zip` — пути внутри архива относительно корня без дополнительной обёртки. Не включает `.github/workflows`.

## Новый интерфейс

- С главного Wallet нажать на мини-карточку BTC/ETH/SOL в разделе «Рынок» — откроется полноэкранный график.
- Со страницы любого актива нажать «LIVE график» в рыночном блоке.
- В правом верхнем углу LIVE-экрана: Системная / Светлая / Тёмная. Выбор глобальный, идентичный настройке «Внешний вид» в профиле; сохраняется через `spyder.wallet.appearance`.
- BTC/ETH/SOL: LIVE (5 мин), 15М, 1Ч получают реальные минутные данные Coinbase Exchange REST (`api.exchange.coinbase.com/products/{TICKER}-USD/candles`) и продолжаются WebSocket-сделками (поток `ws-feed.exchange.coinbase.com`). 1Д/7Д/1М — история CoinGecko с новыми доступными торговыми тиками Coinbase.
- USDT/USDC: только 1Д/7Д/1М; без ложного статуса LIVE, так как поток Coinbase USD в приложении не настроен.
- Точка последней сделки и подсветка, зелёная/красная линия по фактическому направлению за период, интерактивное удержание с датой и ценой, шкала цены справа, Reduce Motion.
- Данные публичные; никакой wallet address, seed, private key или идентификатор пользователя не отправляется рыночным API.

## Важные ограничения

1. Live — это события сделок биржи Coinbase, **не** постоянно обновляемая цена без сделок, не best bid/ask, не агрегированный курс рынка и не гарантированная цена исполнения.
2. Coinbase REST и CoinGecko могут ограничить доступ или запросы. Нет заглушек с выдуманными рыночными значениями: при недоступности источника показывается последний доступный массив реальных данных, предупреждение или пустой график.
3. WebSocket активен только пока приложение активно. После повторного открытия короткая история загружается с публичного REST; старые тики вне выбранного окна не сохраняются.
4. Отправка BTC/ETH/SOL Mainnet не включается этим обновлением. Платёжные функции, seed/Keychain, Spider Chain, чат, E2EE, Motion Kit и CI workflows не меняются.
5. Реальный `xcodebuild` в этой Linux-среде отсутствует. Swift typecheck рыночного Foundation/Combine кода и Swift parse интерфейса **не равны** полноценной iOS компиляции. Перед TestFlight сначала запустить build-only в GitHub Actions, проверить на iPhone 11/13 mini светлую и тёмную темы, график с реальными событиями и ошибки сети.

## Основные файлы

`Console/Features/Wallet/WalletLiveStageView.swift` — нативный полноэкранный Swift Charts UI.
`Console/WalletCore/WalletLiveCandles.swift` — API загрузка с лимитами, кэшем, отменой.
`Console/WalletCore/WalletLiveCandleDecoder.swift` — строгое чтение рядов реальных минутных свечей.
`Tests/WalletLiveCandlesTests.swift` — unit-тесты декодирования.
`ci/tests/test_wallet_dual_theme_live.py` — дополнительные статические и typecheck-гейты.
