## Block 3 — портфель, read-only история, провайдеры

- Новый `WalletActivityStore` с раздельными загрузкой, ошибками и временем обновления по BTC/ETH/SOL; предотвращает смешивание результатов при переключении кошельков. Данные только в памяти; кэш очищается при блокировке приложения и переключении аккаунтов.
- Bitcoin: список входящих/исходящих транзакций и суммы по адресу из Esplora (Blockstream / mempool.space), подтверждения и pending. Раздельные confirmed BTC и mempool delta (unconfirmed не выдаются за свободные средства).
- Ethereum: основной список ETH-транзакций из Blockscout v2, плюс отдельная проверка ERC-20 Transfer для allowlist контракта USDT/USDC. Ограничение: по публичному API история может быть неполной, внутренние операции не индексируются.
- Solana: `getSignaturesForAddress` с данными времени, статуса и обозревателем. **Суммы и направление движения SOL не утверждаются**, потому что этот RPC не предоставляет достаточных данных без парсинга `getTransaction`.
- Для всех операций — переход к обозревателю по hash, лента последних операций, отдельный экран истории, кнопка обновления.
- Резервные публичные RPC для ETH и SOL, альтернативные REST Esplora для BTC, явная маркировка частичной/устаревшей оценки портфеля. Доверять любому отдельному RPC для подписания нельзя. Единый каталог **строго проверенных** токенов, никакого автоопределения по ticker.
- Исправлен маршрут SPD из чата: отдельный экран тестовой отправки SPD, а Mainnet Send остаётся заблокированным. Конфигурированный Spider Devnet выводится как отдельно маркированный тестовый модуль.

## Block 4 — Spyder Network и E2EE v2 (первый защищённый протокол)

- Криптографические ключи чата X25519 + Ed25519 в `ThisDeviceOnly` Keychain, отдельно от BIP-39.
- Шифрование ChaChaPoly с HKDF-SHA256, ephemeral X25519 на каждое сообщение, подписанные конверты для отправителя и получателя. Серверный `/v2/messages` хранит только ciphertext. Сервер v1 (plaintext) не поддерживается — закрытие без fallback.
- Обязательная TOFU-проверка публичных ключей и pin; при изменении ключей отправка блокируется. Отпечаток для сверки с контактом доступен на странице чата; **первое знакомство без сверки не защищено от MITM**.
- Блокировка контактов на сервере, поиск по username включается только с согласия пользователя (по умолчанию профиль скрыт), страница Spyder Identity/Privacy.
- Очистка расшифрованных сообщений при уходе приложения в background.
- Серверный rate limit, строгие форматы зашифрованных сообщений, Node-тесты.

## Что НЕ заявляется как готовое production

- Сам протокол E2EE **НЕ аудирован**, не поддерживает Double Ratchet/forward secrecy для хранимого архива, кросс-девайс/автоматическое восстановление чатов, ключевую прозрачность, push и ротацию ключей. Это экспериментальная v2 основа. Резервная копия seed от кошелька НЕ восстанавливает ключи чата.
- Старые plaintext-сообщения v1 могут оставаться в серверной базе. Их безопасное удаление и пользовательский экспорт/миграция — отдельная работа.
- Нет production-grade full-history индексатора и всех токенов/сетей, надёжного мониторинга, сканирования NFT, полной пагинации всех транзакций. Проверяйте explorer.
- Mainnet Send/Swap, комиссии, подпись BTC/ETH/SOL и broadcasting **по-прежнему выключены** до прохождения финансовых/криптографических тестов.
- Нельзя считать архив завершённым релизом до успешного Xcode build, iOS unit/UI/integration тестов на устройствах и независимого security review.

## Проверка до TestFlight

1. `python3 -m unittest discover -s tests -p 'test*.py' -v`; `cd server && npm run check`.
2. На macOS: `xcodegen generate --spec project.yml`, `xcodebuild -project Console.xcodeproj -scheme Console -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build`.
3. Запустить unit tests `SpyderE2EEV2Tests` в iOS Simulator. ДВА устройства для переписки, сверки отпечатков и изменения публичного поиска.
4. Проверить новые/старые аккаунты, recovery wallet, переключение кошельков, отсутствие старых балансов/операций; BTC unconfirmed и ERC-20 USDT/USDC, тестовые SPD отдельно.
5. iPhone 11 / 13 mini: RU/EN, тёмная/светлая тема, Dynamic Type, VoiceOver, safe areas, Reduce Motion.
6. Рекомендация: до security review **не хранить значительные реальные активы и не отправлять секреты в чаты**.
